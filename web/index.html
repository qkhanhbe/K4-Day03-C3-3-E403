1. Bảng Chấm Điểm Agentic Fit (Role 5 Evaluation)

Đánh giá tính phù hợp của bài toán khi sử dụng ReAct Agent so với Chatbot thông thường.

18 / 20
KẾT LUẬN: RẤT NÊN DÙNG REACT AGENT
Tiêu chí Điểm Lý do đánh giá thực tế
🧠 Multi-step Reasoning 4/5 Đòi hỏi Agent suy luận 2-3 bước: nhận diện đặc điểm ➔ tra cứu Alter Ego ID ➔ lập phác đồ tư vấn 3 bước.
🛠️ Tool Interaction 5/5 Cần gọi các tool chuẩn hóa: analyze_alter_ego, get_counseling_action_plan, assess_psychological_risk.
🔀 Dynamic Decision 5/5 Kết quả phân tích nhân cách & rủi ro ở bước trước quyết định trực tiếp phác đồ tư vấn hoặc ngắt lặp khẩn cấp ở bước sau.
⏳ Long Horizon 4/5 Agent nhớ & xâu chuỗi dữ liệu trong suốt chuỗi Thought-Action-Observation.

2. Nhật Ký Giám Sát Trace Log (Role 5 Observability)

So sánh chi tiết hành vi giữa Chatbot Baseline (Cấp 2) và ReAct Agent (Cấp 3).

🤖 Chatbot Baseline (Cấp 2) Không Tool
  • Chỉ dựa vào tri thức huấn luyện tĩnh của LLM.
  • Trả lời mượt mà nhưng **không tra cứu được dữ liệu nhân cách chuẩn**.
  • **Thất bại khi xử lý Red Flags khẩn cấp** (không có phanh Guardrails).
🧠 ReAct Agent (Cấp 3) ReAct Loop
  • Thực thi quy trình Thought ➔ Action ➔ Observation.
  • Gọi chính xác các tool nghiệp vụ chuẩn hóa dữ liệu JSON.
  • **Tự động ngắt lặp khẩn cấp** khi phát hiện rủi ro (Guardrails).

3. Phân Công 5 Roles & Tiến Độ Thực Hành

Role 1: Business Analyst
Xây dựng bộ 5 Test Cases chuẩn hóa trong config/test_cases.json.
Role 2: Tool Engineer
Khai báo danh sách Tool specs & schemas trong src/tools.py.
Role 3: Prompt Engineer
Soạn System Prompt & Phanh Guardrails trong src/prompts.py.
Role 4: Core Agent Developer
Ghép nối & khởi tạo ReAct Loop trong src/app.py và Web Server.
Role 5: Observability & Reviewer
Chấm điểm Scoring Matrix (18/20) & theo dõi nhật ký Trace Log.
