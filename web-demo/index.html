Tool 1

🔍 analyze_alter_ego[traits]

Phân tích hành vi mâu thuẫn để khai quật "Nhân cách thứ 2" (Alter Ego ID) chuẩn hóa trong cơ sở dữ liệu.

📥 Input: traits (Đặc điểm tính cách, mâu thuẫn cảm xúc)
📤 Output JSON:
  • alter_ego_id: free_child, hidden_volcano, anxious_achiever, hedgehog_dilemma, solitary_sage
  • alter_ego_name & core_conflict
  • risk_level: Low / Medium / High
Tool 2

📋 get_counseling_action_plan

Xuất phác đồ tư vấn hành động 3 bước chuẩn y khoa dựa trên ID nhân cách & mức độ rủi ro.

📥 Input: alter_ego_id, risk_level
📤 Output JSON (Phác đồ 3 bước):
  • step_1_first_aid: Sơ cứu giải tỏa cảm xúc khẩn cấp
  • step_2_cognitive: Nhận thức & xoa dịu mâu thuẫn nội tâm
  • step_3_practice: Bài tập thực hành giao tiếp & hành vi
Tool 3

🚨 assess_psychological_risk

Đánh giá nguy cơ tâm lý nguy hiểm khẩn cấp (Red Flag: tự làm tổn thương, tự tử, ảo thính, bế tắc).

📥 Input: symptoms (Triệu chứng nguy cơ)
📤 Output JSON (Cảnh báo Red Flag):
  • risk_status: RED_FLAG
  • urgency: CRITICAL
  • Tự động ngắt phân tích & kích hoạt Hotline 111 / 115
Guardrail Engine

🛡️ Phanh An Toàn & Giới Hạn

Bộ kiểm soát phanh an toàn bảo vệ Agent khỏi bẫy lặp vô tận, dữ liệu rác và prompt injection.

⚙️ Cấu hình phanh Guardrails:
  • MAX_ITERATIONS = 5: Tự động ngắt lặp an toàn khi gặp rác (%#@!) hoặc lỗi lặp.
  • TIMEOUT_SECONDS = 10: Giới hạn thời gian chờ xử lý mỗi Tool.
  • Red Flag Override: Ưu tiên ngắt lặp cấp cứu y tế.
